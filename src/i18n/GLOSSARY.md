# The 900words glossary

> **Proposed 2026-09-11, native review pending.** The words this app uses for
> its own ideas, in every language it speaks. Machine-authored; see
> [REVIEW.md](REVIEW.md) for who has checked what.

A game invents vocabulary, and a player meets each word a dozen times a
session. "Green card" has to be the same two words on the board, in the rules,
in Casey's tips and on the finishing screen — in every language, not just in
English. That is what this table is for, and it is the reason a translation
here is not a sentence-by-sentence job.

**The rule for a session:** before translating a screen, read this table. If a
term you need is missing, add a row in the same PR as the screen, and say so in
the PR body. Never translate a term two ways.

**Two shapes, for a reason.** The topic tables below carry German, Spanish and
Chinese in columns, which is how this file was written when there were three
translations. Seven more landed on 2026-09-12, and an eleven-column table is
not readable by anyone — so those seven are per-language sections at the end.
The English column is the spine either way. If a twelfth language arrives,
convert the topic tables to the same per-language shape rather than adding a
column; the value of this file is that ONE language is internally consistent,
and that is a per-language question.

## Traps worth naming

Each of these cost a decision during Phase 1; the bold rows above are where two
groups disagreed and had to be reconciled.

- **German "Zug" is the train AND a move in a game.** On a screen that has
  both, a move is `Spielzug` so the train stays the train, and whose turn it is
  is `Zug`.
- **German "Reisepass" is a PASSPORT.** The travel pass is `Reiseticket`, kept
  distinct from `Fahrkarte`, the card the onboarding flow hands you.
- **Packing and wrapping are two things in the English, so they are two in
  every language.** You PACK a card in the dock (`einpacken`, `meter en la
  maleta`, `装进行李箱`); a word that survives a wrap-up round is WRAPPED
  (`eingewickelt`, `envuelta`, `已打包`). Groups 1b and 1c chose differently
  and were reconciled onto 1c's, because Home and the suitcase are where a
  player meets the word.
- **Chinese "Survival" is 生存会话, the section; one dialogue inside it is
  对话.** Groups 1d and 1f differed; the guide owns the section name.
- **Spanish never assumes the player's gender.** Prefer a construction that
  needs no agreement (`Te damos la bienvenida`, not `Bienvenido`).
- **Chinese does not change a noun for the number**, so a plural entry is a
  function that ignores its argument for the noun and uses it only where the
  digit is read.
- **German "neutral" alone would equal the English**, which gate 3 refuses, so
  it is `neutrale Karte` — a noun phrase, which reads better anyway.
- **German "Tipp" must never mean a guess.** It is Casey's rotating tip, and
  `tippen` is "to tap". A guess is `Rateversuch`, the verb is `raten`, and a tap
  is `antippen`. The first machine pass used `Tipp` for all three at once, which
  in a game built on Hinweis-and-raten is a comprehension bug, not a wording one.
- **Spanish `adivinar` implies success.** It is telic: "Casey adivinó X — carta
  neutral" is a contradiction, because she did not in fact get it. Use
  `adivinar` for the activity and the phase, and `ha dicho` where the outcome
  follows in the same breath.
- **Spanish `conseguir` is reserved for collecting a word.** "Get a travel pass"
  is `Obtener`, so the two do not blur.
- **`billete` and `abono de viaje` are Peninsular** (`boleto`, `pase` elsewhere).
  Kept under the Spain-on-record rule of UL1, and they are the two most
  regionally marked terms in the whole chrome.
- **Chinese avoids 绿 as a verb.** "A green each way" is
  `一来一回都翻到绿色`, not anything built on 绿 alone, which carries a slang
  sense and collides with 绿卡.
- **Chinese has a short form for the dock.** `装箱` is the sanctioned button and
  dock-title form of `装进行李箱`; prose always uses the long form.
- **The dock title has its own row and cannot wrap.** "Pack the board" plus the
  count has about 206px at 360 wide. German and Spanish both overflowed it on
  the day the translations landed and the page did not scroll, so the words were
  simply clipped. `layout-drive` now measures that row in all four languages.
- **Casey is she** in every language: sie, ella, 她 (UL12). She is never
  translated or transliterated, and neither is 900words.

- **German and Spanish need a second word for "the dialogue".** The glossary's
  exchange word is `Dialog`/`diálogo`, so "Exchange 1 of 4 — the phrases, then
  the dialogue" would say the same word twice in one line. The talk inside an
  exchange is `Gespräch`/`conversación`; Chinese keeps 对话 for both because the
  section word there is 生存会话.

## One thing that is NOT a defect

All three reviewers flagged Settings for contradicting itself: the study-phase
option says it "fades after Aalborg" and the help text says it "disappears once
the journey reaches Skagen". Those are the same fact. `STUDY_UNTIL_CITY` is 5,
Aalborg is city 4 and Skagen is city 5, so the phase covers cities up to Aalborg
and is off from Skagen onward. `DECISIONS.md` records the pair as deliberate.
Do not "fix" it into being wrong.

translator who wrote that language's catalogue, and each is used consistently
across all 688 of its values. **The traps below each table are the ones that
language actually hit** — they are worth reading before editing that language,
because every one of them is a place where the obvious word is wrong.

**Traps.** *Correct*, *situation* and *situations* are spelled identically in
French, so gate 3 reads them as untranslated; the answer is the word a French
app would really use (*juste*, *mise en situation*, *En situation*), not an
allowlist entry. Country names need a preposition the pack cannot supply (*au*
Danemark, *du* Danemark), so the ticket says "Destination" and the map
"Direction ${country}". *Deviné* implies success exactly as Spanish *adivinado*
does, so a guess that failed is "Casey **a proposé** X".
